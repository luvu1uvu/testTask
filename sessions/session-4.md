## Размышления

Цель сессии — не реализация, а подготовка контролируемого «наивного прогона»:
запуск отдельного, полностью изолированного Claude Code без доступа к
`AGENTS.md`/`SPEC.md`/журналу текущего проекта, чтобы потом честно сравнить,
что агент делает без спецификации и правил против того, что получится по
согласованной спеке. Если наивную сессию запустить в этой же папке проекта,
она неизбежно подхватит `CLAUDE.md` → `AGENTS.md` (правило проекта: файл
подключается автоматически при старте) — сравнение потеряло бы смысл.
Отсюда требование отдельной, физически пустой директории вне `TestTask`.

Перед созданием папки проверил, не существует ли она уже и не содержит ли
чужих данных — по инструкции пользователя в этом случае нужно остановиться,
ничего не удаляя. Каталог `/Users/ranis/Documents/AI/TestTask-naive`
отсутствовал, поэтому просто создал пустую директорию, ничего в неё не
копируя (специально не переносил ни `AGENTS.md`, ни `SPEC.md`, ни материалы —
именно это и обеспечивает «наивность» прогона).

Прогон в этой папке не запускаю сам — согласно прямому указанию пользователя,
это должна быть отдельная чистая сессия Claude Code, которую пользователь
откроет сам.
